## Featured work

### 1. Customer Churn Prediction — flagship customer analytics case

- **Business question:** Which customer patterns are associated with churn, and where should retention efforts be prioritised?
- **Analysis:** Public IBM Telco data and interpretable logistic regression; **ROC-AUC 0.842** on a held-out **20% test set**.
- **Key finding:** **42.7%** churn among month-to-month customers. Average tenure was **18.0 months** for churned customers versus **37.6 months** for non-churned customers.
- **Decision relevance:** Retention-prioritisation recommendations, including onboarding support and targeted outreach. Observed relationships do not establish causation; recommendations need validation in a new business context.

Python · pandas · scikit-learn · Streamlit · [Live demo](https://customer-churn-prediction-using-machine-learning-8u58yeufi66lk.streamlit.app/) · [Repository](https://github.com/stevedudu9/customer-churn-prediction-using-machine-learning)
